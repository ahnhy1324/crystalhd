# Mandatory project instructions

Before working on this repository, read [EXTERNAL-CODE-POLICY.md](EXTERNAL-CODE-POLICY.md).

**We do not modify third-party code.** No patches to external Kodi, FFmpeg,
GStreamer, Mesa, GTK, kernel core, libraries, binaries or firmware. This also
prohibits modified copies/excerpts in tests, temporary trees and private builds.
Do not create or apply an external fix as an investigation shortcut.

Fix maintained CrystalHD components and project-owned integration code. Use
unmodified external components and preserve genuine failures and unsupported
boundaries. Historical patched-external results are not stock compatibility
or release acceptance. Follow the full policy for scope and provenance.
